# CustomOS: Экспериментальная 2-битная операционная система

## Назначение
CustomOS — независимая операционная система с собственной средой выполнения программ, двухбитной графической подсистемой (4 цвета), собственным форматом исполняемых файлов (CBX) и виртуальным диском приложений (AppFS).

## Архитектура системы (Этап 6)
- **Целевая платформа:** x86 (IA-32, 32-bit Protected Mode).
- **Спецификация загрузки:** Multiboot 1 (`qemu-system-i386 -kernel bin/customos.elf`).
- **Стек ядра:** 16 КБ.
- **Подсистема прерываний:** IDT (256 векторов), PIC 8259, обработка системных исключений CPU.
- **Аппаратный таймер:** PIT 8254 на частоте 100 Гц.
- **Ввод:** PS/2 Keyboard с поддержкой стрелок (`uint8_t`).
- **Графическая подсистема:** 320x200, 2 bpp (4 оттенка), буфер 16 КБ, растровый шрифт 8x8, двойная буферизация.
- **Файловая система:** AppFS v1 (каталог и хранилище приложений).
- **Пользовательский интерфейс:** Графический оконный Лаунчер с навигацией и панелью информации.

## Установленные приложения
1. **AppTest:** Базовый тест загрузчика и изоляции памяти.
2. **SysInfo:** Диагностический модуль характеристик и адресов CustomOS.
3. **TextDemo (Обязательное приложение № 1):** Текстовое форматирование, табличный вывод и динамическая смена цветового контраста клавишей `[C]`.
4. **LogicCalc (Обязательное приложение № 2):** Логический и арифметический стенд (проверка формул, битовой логики, Фибоначчи, простых чисел) и интерактивный инспектор чисел `[+]` / `[-]`.

## Управление
- `Стрелки Вверх / Вниз` или `W / S` — перемещение курсора выбора в Лаунчере.
- `[ENTER]` — запуск выбранной программы.
- `[SPACE]` или `[ESC]` внутри любого запущенного приложения — безопасный возврат в меню Лаунчера.
