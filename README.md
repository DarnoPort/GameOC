# CustomOS: экспериментальная 2-битная операционная система

## Назначение

CustomOS — экспериментальная 32-битная x86-операционная система для запуска собственных приложений в формате CBX. В состав входят графическая подсистема 320×200 с четырьмя оттенками, клавиатура PS/2, таймер, API приложений и встроенный каталог AppFS.

## Архитектура

- **Платформа:** IA-32, Multiboot 1.
- **Сборка ядра:** GCC, NASM и GNU LD.
- **Прерывания:** IDT, PIC 8259, обработчики исключений CPU.
- **Таймер:** PIT на 100 Гц.
- **Графика:** 320×200; внутренний упакованный буфер 2 bpp, вывод через VGA Mode 13h; шрифт 8×8.
- **Приложения:** CBX v1, загружаемые по адресу 0x00400000; их API предоставляет текст, графику, ввод и задержки.
- **Каталог программ:** AppFS, встроенный в образ ядра при сборке.
- **Запуск:** графический лаунчер с навигацией и описанием выбранного приложения.

> Важно: отдельный стек приложения — это пока не аппаратная изоляция памяти. Приложения работают в том же адресном пространстве и уровне привилегий, что и ядро.

## Приложения

1. **AppTest** — проверка загрузчика CBX и вызовов API.
2. **SysInfo** — диагностическая информация о системе.
3. **TextDemo** — демонстрация текстового рендерера, многострочной раскладки и смены контраста клавишей C.
4. **LogicCalc** — тесты арифметики и логики, интерактивный инспектор чисел.
5. **Dodge** — игровое приложение, построенное на мини-движке из `apps/app_game/game_engine.c` и `apps/app_game/game_engine.h`.

### Этап 7: игровой движок и игра №3

Мини-движок предоставляет простую модель сущностей: позицию и размеры, скорость, цвет, активность, границы игровой области, обновление объектов, ограничение движения, удаление объектов за пределами арены, проверку прямоугольных столкновений и отрисовку.

**Dodge** использует этот движок для игры на выживание: управляйте светлым квадратом и избегайте падающих блоков. Со временем скорость и частота появления опасностей растут. Лучший результат хранится, пока приложение запущено.

**Управление Dodge:**
- Стрелки или **W/A/S/D** — перемещение.
- **P** — пауза и продолжение.
- **R** или **Enter** после столкновения — новая попытка.
- **Space** или **Esc** — вернуться в лаунчер. На стартовом экране **Enter** начинает игру.

## Управление лаунчером

- **Стрелки вверх/вниз** или **W/S** — выбор приложения.
- **Enter** — запуск выбранного приложения.
- **Space/Esc** внутри приложений — выход обратно в лаунчер.

## Сборка и запуск

В Ubuntu/WSL из корня репозитория:

```bash
make clean
make
make run
```

Команда `make` компилирует приложения, упаковывает их в CBX, создаёт AppFS и встраивает его в ядро. `make run` запускает образ через `qemu-system-i386`.

Для сборки нужны GCC с поддержкой 32-битного кода, NASM, GNU LD, Python 3 и QEMU.
